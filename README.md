
# ValutaTrade Hub

ValutaTrade Hub — консольное приложение на Python для управления виртуальным валютным портфелем.

Приложение позволяет регистрировать пользователей, покупать и продавать валюты, отслеживать балансы и получать актуальные валютные курсы через внешние API.

Все операции выполняются с виртуальными средствами. Реальные денежные переводы не поддерживаются.

## Возможности

- Регистрация и авторизация пользователей.
- Хранение паролей в виде хешей с солью.
- Управление персональным валютным портфелем.
- Пополнение виртуального USD-баланса.
- Покупка и продажа поддерживаемых валют.
- Получение курсов фиатных и криптовалют.
- Кэширование валютных курсов.
- Автоматическое обновление курсов в фоновом потоке.
- Сохранение пользователей, портфелей и курсов в JSON.
- Логирование операций и ошибок.
- Автоматическое тестирование с pytest.

## Поддерживаемые валюты

Фиатные валюты:

- USD
- EUR
- RUB
- GBP
- JPY

Криптовалюты:

- BTC
- ETH
- SOL
- ADA
- DOGE

Базовая валюта приложения — USD.

### Основные модули

**core/** — бизнес-логика приложения: пользователи, кошельки, портфели и торговые операции.

**infra/** — работа с JSON-хранилищем и настройками приложения.

**parser_service/** — получение валютных курсов, кэширование и фоновое обновление.

**cli/** — консольный интерфейс и обработка пользовательских команд.

**decorators.py** — декораторы логирования операций и измерения времени выполнения.

**logging_config.py** — настройка журналирования и ротации лог-файлов.

## Установка

Для запуска необходимы Python 3.14 или новее и менеджер пакетов uv.

Клонируйте репозиторий:

```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd valutatrade-hub
```

Установите зависимости:

```bash
uv sync
```

Запустите приложение:

```bash
uv run valutatrade
```

После запуска появится интерактивный интерфейс:

```text
ValutaTrade Hub
Введите help для списка команд.

>
```

## Команды приложения

| Команда | Назначение |
|---|---|
| `register` | Регистрация пользователя |
| `login` | Авторизация |
| `logout` | Выход из учётной записи |
| `deposit` | Пополнение виртуального USD-баланса |
| `show-portfolio` | Просмотр валютного портфеля |
| `buy` | Покупка валюты |
| `sell` | Продажа валюты |
| `update-rates` | Принудительное обновление курсов |
| `get-rate` | Получение курса конкретной валюты |
| `show-rates` | Просмотр доступных курсов |
| `help` | Справка по командам |
| `exit` | Завершение работы |

## Источники валютных курсов

Приложение использует два внешних источника:

**CoinGecko API**

Предоставляет курсы криптовалют BTC, ETH, SOL, ADA и DOGE относительно USD.

**ExchangeRate API**

Предоставляет данные для расчёта курсов фиатных валют EUR, RUB, GBP и JPY относительно USD.

Полученные данные сохраняются локально в JSON.

### Кэширование

Приложение использует локальный кэш валютных курсов.

По умолчанию срок актуальности кэша составляет 300 секунд.

Если кэш актуален, повторный запрос к внешнему API не требуется.

### Фоновое обновление

Во время работы консольного приложения запускается отдельный поток, который периодически обновляет валютные курсы.

Интервал обновления — 300 секунд.

При завершении приложения планировщик останавливается.

## Хранение данных

Данные сохраняются в локальных JSON-файлах:

- `data/users.json` — пользователи.
- `data/portfolios.json` — валютные портфели.
- `data/rates.json` — текущие курсы.
- `data/exchange_rates.json` — история обновлений курсов.

Пароли в открытом виде не сохраняются.

## Логирование

Приложение записывает информацию о выполненных операциях и ошибках в журнал:

```text
logs/actions.log
```

Для ограничения размера журнала используется ротация лог-файлов.

Логируются регистрация, авторизация, торговые операции, ошибки и работа фонового планировщика.

## Тестирование

Для запуска всех автоматических тестов:

```bash
uv run pytest -v
```

Для краткого вывода:

```bash
uv run pytest -q
```

Тесты проверяют:

- модели пользователей и кошельков;
- работу портфелей;
- регистрацию и авторизацию;
- покупку и продажу валют;
- недостаток средств;
- обработку некорректных сумм;
- ошибки внешних API;
- сохранение результатов операций;
- работу фонового планировщика.

Внешние API в тестах подменяются, поэтому для их выполнения интернет не требуется.
